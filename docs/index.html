Privacy Policy

TreeDisk — Android Storage Explorer
Effective Date: August 8, 2026

100% On-Device & Privacy Focused

TreeDisk processes and analyzes all device storage data locally on your Android device. We do not collect, transmit, store on servers, or share any personal information or file content with anyone. TreeDisk operates without requiring internet access.

1. Overview

This Privacy Policy describes how Logic Rift Labs ("we", "us", or "our") handles information in connection with the TreeDisk mobile application for Android.

Our core commitment is transparency and data minimization. TreeDisk is designed purely as a local utility application to help users visualize, analyze, and manage disk storage on their Android devices.

2. Information We Access & Permissions Required

To calculate disk usage, analyze folder structures, and organize media file categories, TreeDisk requests access to Android system permissions. Below is an explicit breakdown of requested permissions and their functional purpose:

  • MANAGE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE: Used exclusively to scan file sizes, directory trees, and allow user-initiated file operations (such as viewing or cleaning up storage).
  • READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO: Used on Android 13+ to categorize media file space usage (photos, videos, audio tracks) so users can see visual storage distribution.

Important Note: All storage scanning and metadata calculation occurs exclusively in real-time on your device CPU/RAM. File content, file names, directory listings, or personal media are never sent off your device.

3. Data Collection and Transmission

TreeDisk has zero networking features:

  • No Internet Permission: TreeDisk does not request the INTERNET permission in AndroidManifest. XML. It physically cannot communicate with external servers.
  • No Personal Data Collection: We do not collect names, email addresses, IP addresses, location data, device identifiers (GAID/IMEI), or contacts.
  • No Analytics or Tracking SDKs: TreeDisk contains no third-party analytics frameworks (e.g., Google Analytics, Firebase Analytics, Mixpanel, AppFlyer).
  • No Advertising SDKs: TreeDisk is ad-free and contains no ad networks or tracking scripts.

4. Third-Party Services

Because TreeDisk runs entirely locally and offline, no data is shared with third parties, vendor APIs, cloud servers, or advertising networks.

5. Data Retention & Deletion

Since we do not collect or store any user data on servers or databases, there is no remote data to retain or delete. All temporary app memory used during storage scanning is released automatically when the application is closed. Uninstalling TreeDisk removes the app completely from your device.

6. Children's Privacy

TreeDisk does not collect any personal information from anyone, including children under the age of 13. TreeDisk is safe for users of all ages and complies with the Children's Online Privacy Protection Act (COPPA) and General Data Protection Regulation (GDPR).

7. Changes to This Privacy Policy

We may update our Privacy Policy from time to time to reflect changes in legal requirements or application features. Any updates will be posted directly on this page with a revised "Effective Date".
