# Privacy Policy for TreeDisk

**Effective Date:** August 8, 2026

**Application:** TreeDisk — Android Storage Explorer (`com.logicriftlabs.treedisk`)  

---

## 1. Overview

**Logic Rift Labs** ("we", "us", or "our") built **TreeDisk** as an Android storage analysis tool. This Privacy Policy outlines how our application operates and handles device permissions and user privacy.

Your privacy is our top priority. **TreeDisk operates 100% on-device and offline.** We do not collect, transmit, store, or share any personal data, usage data, or file information.

---

## 2. Permissions Required & Purpose

TreeDisk requires specific Android storage permissions to perform its core functions—scanning disk space usage, analyzing directory sizes, and categorizing media files.

- **`android.permission.MANAGE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE`**: Enables TreeDisk to analyze file trees, compute folder sizes, and allow user-directed file management.
- **`android.permission.READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` / `READ_MEDIA_AUDIO`**: Enables media file grouping and visual disk usage analysis by file type on Android 13+.

> **Note:** All storage analysis is processed in real time in device memory. No content or directory information is saved to external servers or transmitted off the device.

---

## 3. Data Collection, Tracking & Analytics

- **No Network Transmission:** TreeDisk does **not** include the `INTERNET` permission in `AndroidManifest.xml`. It cannot transmit data over network connections.
- **No Personal Data Collected:** We do not collect names, email addresses, device IDs, location, contacts, or file data.
- **No Third-Party Analytics:** TreeDisk does not integrate third-party analytics SDKs (e.g., Firebase Analytics, Google Analytics).
- **No Advertising:** TreeDisk is ad-free and contains no ad networks or tracking libraries.

---

## 4. Third-Party Access

Since TreeDisk does not communicate with external servers or third-party APIs, **no user data is shared with any third parties.**

---

## 5. Security & Storage

- All operations occur locally on your device.
- TreeDisk does not store user data remotely. Uninstalling the app completely removes all local app state from your device.
